# Full dictionaries with reproducible, committed inputs

Download `bees-ultimate-grammar-dictionary.zip` for the original edition or
`bees-ultimate-grammar-dictionary-en.zip` for the separately installable English
edition. Import the ZIP in Yomitan Settings → Dictionaries → Import.

Both editions contain **6,371 lookup entries across all 13 grammar sources**,
including **494 IMABI lessons**. English translations of monolingual content are
labelled GPT-6 Luna translations; source-authored English is retained.

## IMABI source data now ships in the repository

The existing full publication snapshot already contained IMABI. This release
also commits its raw acquisition: **501 WordPress pages**, the page index,
coverage report and SHA-256 source lock. Extraction imports 494 lessons and
excludes seven site pages. The new acquisition has 18,876 numbered examples,
18,158 with author-supplied English translations.

## Rebuild the full release from a fresh clone

```sh
python3 -m venv .venv
.venv/bin/pip install .
make
```

The default build uses the committed full corpus and cached English translations.
After installing dependencies, it runs offline: no missing local Anki decks,
new scraping or model credentials are needed. The publication corpus retains
its existing normalization, deduplication and corrections; the raw IMABI
acquisition is independently locked for future source refreshes.

Both ZIPs, both update indexes and `SHA256SUMS` are in `build/site/downloads/`.
The repository pins their exact hashes and byte counts in
`website/data/release.json`.

## Verification

The release build checks every committed IMABI source digest, full source and
lesson coverage, both ZIPs against the pinned official Yomitan schemas, all
12,742 dictionary-to-article links and their article headings, and the exact
release asset hashes. Stable published article addresses are preserved.

To verify the downloaded ZIPs:

```sh
sha256sum -c SHA256SUMS
```

The release workflow rebuilds and verifies these committed inputs before
uploading the assets. Future builds fail if the bytes differ from the lock.
