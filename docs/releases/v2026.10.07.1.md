# Japanese popup lookup across every source

All **9,152 source records across 13 sources** now have Japanese lookup forms
or Japanese topic labels. Both full editions contain **7,633 term-bank rows**.

- Expand grammar notation into searchable Japanese: `Nらしい` → `らしい`,
  `AながらB` → `ながら`, and `ば〜ほど` → `ほど`.
- Resolve generic Bunpro titles from each record's actual construction; add
  kana spellings with checks against malformed source readings.
- Index all **495 IMABI lessons under 1,400 Japanese terms**, including compound
  forms such as `ことにする`, `ことがある` and `のみならず`.
- Restore IMABI's “About” grammar lesson under `について`, `に関して`,
  `をめぐって` and `をめぐり`, with all 38 bilingual examples.
- Enable conjugated lookups for known grammar endings: `すぎた`, `にくかった`,
  `込んだ`, `てこなかった` and `ことにした`.
- Restore missing HJGP popup disclosures for articles stored in the meaning
  field. Keep source-page-only listings visible and clearly labelled too.
- Keep all previous headwords and article URLs, full explanations, attribution
  and cached English translations. Popup disclosures link to any extra senses.

Update or reimport the dictionary in Yomitan. Try hovering `について` in
`政治について話す。` or `ことにした` in `毎日読むことにした。`

Reference lessons use Japanese topic queries such as `母音` or `古典文法`.
Discontinuous grammar is found at its written particle or ending; the dictionary
does not automatically parse arbitrary gaps in a sentence.

Both ZIPs are checked against the pinned schemas, every source-record lookup
and full article, all dictionary footer links, old routes and SHA-256 hashes.
Sentence lookup tests use the committed upstream Yomitan engine and the actual
ZIP rules. All build inputs and tests are committed for offline reproduction.

- `bees-ultimate-grammar-dictionary.zip`: original source edition.
- `bees-ultimate-grammar-dictionary-en.zip`: English edition.
- `SHA256SUMS`: archive checksums.

See [coverage, examples and verification details](https://github.com/bee-san/bees-ultimate-grammar-dictionary/blob/main/docs/lookup-coverage.md).
