# IMABI particle and grammar lookup fix

IMABI now appears when looking up ordinary Japanese grammar forms instead of
requiring its English lesson titles. This release indexes **267 lessons under
501 Japanese terms**, with 609 explicit lesson-to-term links.

Examples to try: **は, が, を, に, へ, で, の, と, も, から, まで, けど,
ぐらい, のだ, んだ, にくい, ざるを得ない**.

| Lookup | IMABI lessons before | Now |
| --- | ---: | ---: |
| は | 0 | 2 |
| に | 0 | 9 |
| を | 0 | 5 |
| のだ | 0 | 2 |
| けど | 0 | 1 |

Multiple lessons retain their own titles, explanations and attribution. The
popup shows up to four lessons and points to the full article for the rest.
Both the scope and mood lessons appear under のだ and んだ. Combined lesson
titles such as ざるを得ない & やむを得ない have separate Japanese lookup terms.

Both editions contain **6,511 lookup entries across all 13 sources**, retaining
all **494 IMABI lessons**. Every previous article address remains available.
Update or reimport the dictionary in Yomitan to use the new lookup terms.

- `bees-ultimate-grammar-dictionary.zip`: original source edition.
- `bees-ultimate-grammar-dictionary-en.zip`: English edition.
- `SHA256SUMS`: checksums for both archives.

The reviewed lookup catalog, raw IMABI pages, complete base corpus and cached
English translations are committed. `make` reproduces both editions after
installing the pinned dependencies; no scraping or model calls are needed.

Release verification checks every catalogued lookup in both actual ZIPs, every
linked lesson on both websites, all 13,022 dictionary-to-article links, all
previous headwords, source digests, pinned schemas and release asset hashes.
