# Rebuildable from the repository alone

This release makes the whole dictionary reproducible from this repository and
its sources' own public downloads, and publishes the first snapshot built
that way.

Until now, a release was built from a frozen merged corpus. Three of its
sources (the AIUEO, Bunpro and 文法 Anki decks) existed only as local files that
are now gone, and IMABI's records came from an older extraction that the current
extractor no longer produces. Now:

- `make acquire` downloads every source that is still published (DoJG, Donna
  Toki, 毎日のんびり日本語教師, 絵でわかる日本語 and its illustrated edition, HJGP,
  Yokubi) from the pinned URL in its lock, and checks every byte against the
  lock's SHA-256.
- Inputs with no public download are committed: NINJAL's CC BY 4.0 database
  (its repository was returning errors), くらべてわかる, HJGP EN, the scraped
  日本語NET banks, and the extracted records of the three Anki decks, exactly as
  every release has used them.
- `make verify-rebuild` rebuilds everything in a clean export of the repository
  and checks that it reproduces the committed snapshot and these release
  archives byte for byte. A new GitHub workflow runs it for every change and
  weekly.

Rebuilding IMABI with the current extractor changes two things in the
dictionary:

- The IMABI lesson 「About」 (について, に関して, をめぐって) now sits in its normal
  place in the dictionary instead of being appended last.
- IMABI's 「The Mood Marker ～のだ」 lesson fixes a typo in one example
  (`いつく作れる` → `いくつ作れる`) and a doubled space.

Nothing else changes. Every headword and article URL published through
v2026.11.08 is kept and checked.

- `bees-ultimate-grammar-dictionary.zip`: original source edition.
- `bees-ultimate-grammar-dictionary-en.zip`: English edition.
- `SHA256SUMS`: archive checksums.
